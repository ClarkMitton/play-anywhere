# Architecture rules
- Designer-authored Audio & Image stores both media URLs in each screen's content and uses a dedicated manual audio player; playback stays local and never advances slides, so creators can combine it with other screen activities.
- Designer-authored Spot the Difference uses one shared definition for all three roles, selects reference/comparison images at render time, and keys independent live results by session and slot; completion is checked against marked locations so incomplete or inconsistent setups cannot submit. Keep it separate from canonical AI generation files because images and coordinates are user-managed.
- Existing lesson-agent deployments import teaching blocks from `_shared/lessonPromptBlocks.ts`; keep its exported values identical to the canonical generator blocks because deployment excludes sibling function folders.
- Agent conversations retain independent browser-local history, resources and drafts after creation; designer return links identify the conversation so rebuilding never overwrites the created lesson.
- Lesson-agent consumes complete provider streams. With `stream: true` it replies as NDJSON (delta, progress and ping lines, then exactly one `result` line); without it, one JSON object after whitespace heartbeats. The page treats a reply with no `result` line as a failure, never a partial lesson, and stops and resends once any call that goes silent (no answer in 45 s, allowing for a cold start after a redeploy, or 30 s without a line), because calls to the function occasionally hang.
- `designed_slide` (components/DesignedSlide.tsx) is a slide with a layout (cover, split, steps, statement, compare, question) and a look (clean, paper, bold, calm, night), drawn as a card framed on the room's dark grid; touch screens get the tall version. The lesson agent writes them and may leave `image_search`, which the agent page fills with a free Pexels photo through fetch-image before the draft is shown; only lesson-media picture addresses are kept.
- The lesson agent asks its questions as a fenced ```choices JSON block that the agent page turns into clickable cards (with Other); before the first plan of a new lesson the page itself (no AI) asks length, level, learners, tables, printing, the session's feel and must-include / leave-out features, skipping any the first message already answers. Each feel (game show, calm, mystery, debate, making, real-life case) is a fixed recipe in the lesson-agent prompt (FEELS). Wordwall share links are turned into /embed/ addresses at display time through lesson-agent mode "embed", because Wordwall pages refuse to be framed.
- A room's day (`/day`, components/SessionHandover.tsx) is one session whose lesson changes in place: the Host keeps the plan in its own localStorage (`handover:<sessionId>`), warns every screen 2 minutes before each turnover by broadcast, then rewrites the same session row to the next lesson's first slide (or ends it), so touch screens follow without new codes. Keep the Host page open; it is the clock.
